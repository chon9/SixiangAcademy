# 四象學園 Sixiang Academy

以卡為誓，戰出你的傳說！

一款設定在中國高中的角色卡牌對戰遊戲。青龍、白虎、玄武三個學院，三格場地，五行克制，任意兩張卡都能合體。

官方網站：<https://tcg.chon9.com>

## 下載

到 [最新版本](https://github.com/chon9/SixiangAcademy/releases/latest) 下載遊戲。這裡只提供遊戲下載檔和更新紀錄，沒有原始碼。線上對戰、開包和交易需要連上網路並註冊帳號，練習對戰和夜巡不用。

### Windows

下載 `SixiangAcademy-Windows.zip`。需要 64 位元的 Windows。

1. 把 zip 整個解壓縮。不解壓縮就執行，遊戲會打不開。
2. 打開資料夾裡的 `SixiangAcademy.exe`。
3. 如果 Windows 顯示 SmartScreen 警告，按「其他資訊」，再按「仍要執行」。遊戲目前沒有程式碼簽章，所以會出現這個畫面。

### Android（測試版）

下載 `SixiangAcademy-Android.apk`。需要 Android 7 以上的 64 位元手機。

1. 只從官方網站或這裡的版本頁面下載。其他地方的 APK 可能被改過。
2. 在手機上打開 APK。系統詢問時，允許這次安裝。部分手機可能會顯示額外警告或要求等待。
3. HarmonyOS 5 以上不能直接安裝 APK。

電腦版和手機版用同一個帳號，學分和收藏相通。牌組、夜巡進度和秘笈存在各裝置上，不會同步。

## 更新紀錄

### v0.2.0

2026-11-05。這次是大改版，對戰規則也變了。舊版本要更新才能線上對戰。

新規則：

- 兩人成牆：場上有兩名以上角色才能保護英雄。只剩一名時，對手可以選擇打角色或直接打英雄
- 院訣：角色倒下和英雄受傷會累積氣。血量落後時，點自己的面板放院訣，3 氣放小招、6 氣放大招，每個學院的招式都不同
- 絕技：23 張突破卡都有專屬絕技，擊殺、被攻擊、倒下時會自動發動，對手的回合也會
- 伏牌：花 1 靈氣蓋一張牌。對手用被它克制的屬性攻擊時會自動翻開，擋下攻擊並反擊
- 先手的起手牌一定有能上場的角色（牌庫有的話）
- 電腦對手變聰明了，會算斬殺，獻祭也更合理。新增中等難度「學姊」

新內容：

- 夜巡：單人闖關模式，不用帳號也不用連線。走完三層樓，血量會延續，打贏後選牌、選符印，挑戰會破壞校規的對手，最後對上會用你丟掉的牌反擊的夜冥。通關後可挑戰更難的夜考
- 秘笈：收錄 38 張突破卡。沒做過的突破會在手牌標籤上標「新」
- 入學試：第一次開遊戲會有一場引導對戰，隨時可以跳過
- 選單重新整理，會記住你上次的選擇
- 線上補位的電腦改用學園角色登場

更有感的戰鬥：

- 打擊感隨傷害和境界變化，餘勁有衝擊波，連殺會有雙殺、三殺
- 元嬰、化神有全新的登場演出，金丹、築基也分級，重複時會縮短，點一下就能跳過
- 許多招式有專屬演出
- 快分勝負時會進入決戰，敵我都會標示斬殺和致命
- 對戰結束有終結演出和戰績回顧，還能再來一局

修正與調整：

- 一鍵獻祭：不選牌時按獻祭，會直接獻祭標示的卡
- 規則書可以用手指捲動，也有關閉按鈕
- 組牌畫面改成適合手指操作
- 線上倒數現在和伺服器同步。連續兩次超時會由電腦接手
- 夜巡進度和秘笈只存在這台裝置上，不會同步，也不會給學分或卡牌
