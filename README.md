# 四象學園 Sixiang Academy

以卡為誓，戰出你的傳說！

一款設定在中國高中的角色卡牌對戰遊戲。青龍、白虎、玄武三個學院，三格場地，五行克制，任意兩張卡都能合體。

官方網站：<https://tcg.chon9.com>

## 下載

到 [最新版本](https://github.com/chon9/SixiangAcademy/releases/latest) 下載 `SixiangAcademy-Windows.zip`。這裡只提供遊戲下載檔和更新紀錄，沒有原始碼。

1. 把 zip 整個解壓縮。不解壓縮就執行，遊戲會打不開。
2. 打開資料夾裡的 `SixiangAcademy.exe`。
3. 如果 Windows 顯示 SmartScreen 警告，按「其他資訊」，再按「仍要執行」。遊戲目前沒有程式碼簽章，所以會出現這個畫面。

需要 64 位元的 Windows。線上對戰、開包和交易需要連上網路並註冊帳號，練習對戰不用。

## 更新紀錄

### v0.1.1

2026-11-04。

- 新增恢復碼：註冊時會拿到一組代碼，忘記密碼時可以用它重設
- 已經有帳號的玩家，下次輸入密碼登入時會拿到第一組恢復碼
- 恢復碼只顯示一次，請存好；密碼和恢復碼都遺失的話，帳號就救不回來
- 重設密碼後，所有裝置都會登出，24 小時內不能送出物品，以防代碼被盜
- 已登入時可以用密碼更換恢復碼

### v0.1.0

2026-11-04，第一個公開版本。

- 三個學院各 16 名學生，加上 9 名神魔角色，共 57 名角色
- 新增 9 張法寶：直接傷害、賜予護盾、奪取敵方角色、把敵人變成稻草人
- 可以自己組牌：一個學院的學生，加上最多 4 張神魔和 6 張法寶，共 24 張
- 每回合抽 2 張牌，後攻方第一回合多 1 點靈氣
- 練習對戰：離線對戰電腦，有兩種難度，也可以和電腦隊友打 2v2
- 線上對戰：1v1 和 2v2，可以用隊伍代碼和朋友同隊，沒有對手時由電腦補位
- 開包、收藏和交易：只靠對戰賺學分，不賣點數；卡包只解鎖外觀，不影響能力
- 每天前 10 場勝利可以獲得學分
- 所有洗牌、抽牌和開包結果都由伺服器決定，防止作弊
